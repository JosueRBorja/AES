# Transformaciones AES · Práctica de matrices

Ejercicio con SubBytes, ShiftRows, MixColumns y AddRoundKey para estudiar transformaciones del algoritmo.

## Archivo principal

[`Examen2.py`](<Examen2.py>) contiene el ejercicio. El repositorio conserva su nombre histórico para mantener los enlaces existentes.

## Qué permite revisar

Lee el punto de entrada, los datos de ejemplo y el resultado de la operación. Contrasta los datos de entrada con la salida antes de extender el ejercicio.

## Alcance

Implementación de aprendizaje, no una librería criptográfica validada. La autoría original identifica a JR, ZR, MV y WJ, estudiantes de UIDE; se conserva ese reconocimiento.
